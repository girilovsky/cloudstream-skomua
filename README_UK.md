# SkomUA для Cloudstream — alpha

Провайдер https://skomua.online/: чотири категорії, пошук, фільми та серіали з поділом на сезони. Основне джерело відео — Ashdi. Інші плеєри передаються вбудованим екстракторам Cloudstream; їх підтримка залежить від версії застосунку.

## Створення репозиторію

1. Створіть **публічний** GitHub-репозиторій `cloudstream-skomua`.
2. Завантажте до його кореня **весь вміст** цієї папки, включно з `.github` та `gradle`. Через git: `git init -b main`, `git add .`, `git commit -m "Add SkomUA provider"`, `git remote add origin https://github.com/ВАШ_ЛОГІН/cloudstream-skomua.git`, `git push -u origin main`.
3. На вкладці Actions дочекайтеся успішного **Build SkomUA**. Якщо автоматичний запуск не відбувся, натисніть **Run workflow**.
4. Cloudstream → Налаштування → Розширення → Додати репозиторій. URL:

   `https://raw.githubusercontent.com/ВАШ_ЛОГІН/cloudstream-skomua/builds/repo.json`

5. Установіть SkomUA зі списку. За потреби ввімкніть показ бета-розширень.

`repo.json` створюється автоматично в гілці `builds` із правильним логіном і назвою репозиторію. Фіктивного готового URL у цьому архіві немає. Не вставляйте адресу CakesTwix: вона не містить цього нового провайдера.

## Перевірено / обмеження

- Станом на 29.10.2026 перевірено HTML головної, фільму і серіалу, iframe `data-src`, прямий HLS фільму та JSON Ashdi для 2 сезонів / 16 серій «Безхатні виродки».
- Компіляцію Android і відтворення в Cloudstream у цьому середовищі не перевірено. Це вихідний alpha-проєкт, а не перевірений `.cs3`.
- Розширення позначене Beta. Перед релізом потрібні успішна GitHub Actions збірка та перевірка на пристрої: категорії, пошук, фільм, вибір сезону, запуск серії, перемотування.
- URL потоків можуть змінюватися. Якщо відео перестало запускатися після тривалої паузи, відкрийте картку заново.
- Відсутні серії не вигадуються: якщо Ashdi не повернув плейлист, показується помилка. DRM, платні обмеження та авторизація не обходяться.

## Походження інфраструктури

Gradle wrapper і конфігурація збірки адаптовані з https://github.com/CakesTwix/cloudstream-extensions-uk (master, отримано 29.10.2026). Провайдер SkomUA і GitHub Actions додано окремо. Залежності Cloudstream із JitPack потребують доступу з runner до JitPack/Google/Maven Central.
